# Template Diary

Before any task, read these three files and follow them:

- `RULES.md`: engineering rules (mandatory). Always double-check and cross-check, including against the database schema.
- `DEVELOPMENT.md`: phase plan and the database contract (§5). Work one phase at a time; stop for Hasan's review after each phase.
- `DESIGN.md`: the design system (white, light only, Inter for UI, JetBrains Mono for code).

Always work on `main`. Run `npm run check` (and `npm run test:e2e` for UI changes) before every push.
